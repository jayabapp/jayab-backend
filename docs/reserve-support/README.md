## تصمیم‌های قطعی کارفرما

1. **کمیسیون:** ۲۰٪ مبلغ پرداختی مهمان. سهم میزبان ۸۰٪ است.
2. **وعدهٔ ۲۱ دقیقه:** تایمری فقط نمایشی است که به مهمان می‌گوید «جایاب حداکثر تا ۲۱ دقیقه به شما جواب می‌دهد». این تایمر با **اولین پاسخ** متوقف می‌شود و فرایند رزرو زیر آن ادامه پیدا می‌کند. اولین پاسخ می‌تواند جواب ۱ یا ۲ میزبان از هر کانالی باشد، یا هر اقدام پشتیبان روی همان رزرو (تماس، پیامک یا ثبت جواب تلفنی میزبان). رسیدن به دقیقهٔ ۲۱ درخواست را منقضی **نمی‌کند**.
3. **مهلت پرداخت مهمان:** ۱۰ دقیقه بعد از تأیید میزبان. مهلت پیشنهاد جدید پشتیبان و مهلت خرید اشتراک میزبان هم هر کدام ۱۰ دقیقه است.
4. **اختیار پشتیبان:** قیمت و تقویم آگهی را بدون تأیید میزبان تغییر می‌دهد و تغییر بلافاصله اعمال می‌شود.
5. **جواب عددی ۱/۲:** با خط اختصاصی SMS.ir گرفته می‌شود. پنل آوانک هم در دسترس است.
6. **دسته‌های آگهی:** فقط دسته‌های ۳ و ۴ وارد این فلو می‌شوند.

| دسته | شرط | مسیر |
| --- | --- | --- |
| ۱ | اشتراک فعال | روال فعلی (تماس مستقیم) |
| ۲ | بدون اشتراک، احراز نشده | روال فعلی (شمارهٔ پوشیده و دعوت به تمدید اشتراک) |
| ۳ | بدون اشتراک، `is_authorized = true` | **رزرو با جایاب** |
| ۴ | میزبان سوئیچ «فقط رزرو از جایاب» را روشن کرده (`booking_mode = 2`) | **رزرو با جایاب** |

7. **لغو بعد از پرداخت:** طبق قانون کنسلی آگهی (سهل‌گیرانه، متعادل یا سخت‌گیرانه) انجام می‌شود و همان قانون سهم میزبان را تعیین می‌کند. جایاب می‌تواند پله‌های این سه قانون را تغییر دهد و میزبان مجبور است یکی از آن‌ها را انتخاب کند. جزئیات در بستهٔ کیف پول، HW-01 و HW-06.

## قراردادهای مشترک

- پاسخ endpointها از envelope موجود `TransformInterceptor` استفاده می‌کند (`{ result, messageCode }`).
- مبلغ‌ها به تومان و `Int` هستند. سهم میزبان `Math.round(total * (100 - percent) / 100)` و کمیسیون `total - host_share` است تا جمعشان دقیقاً برابر مبلغ کل باشد.
- زمان‌ها در دیتابیس UTC ذخیره می‌شوند و در پیامک و UI به جلالی و ساعت تهران نمایش داده می‌شوند (`moment-jalaali`).
- هر تغییر وضعیت فقط از `ReserveFlowService` (RS-1.6) انجام می‌شود که لاگ می‌نویسد. هیچ controller یا job مستقیم `status` را تغییر نمی‌دهد.
- متن‌های Front در namespace `reserve` فایل‌های `Front/messages/{fa,ar,en}.json` هستند. Panel فقط فارسی است.

## روش بررسی بعد از هر فاز

- **Back:** `yarn lint`، `yarn test`، `npx tsc -p tsconfig.build.json --noEmit`. CLI Nest روی این سیستم خراب است و Postgres و Redis محلی هم نیست، پس تست صف‌ها روی jayab.org انجام می‌شود.

- **Front:** `yarn lint`، `yarn build`، `yarn test:reservations`.
- فازهای ۰۲، ۰۳، ۰۵، ۰۶ و ۰۷ بعد از پیاده‌سازی با `/security-review` بررسی شوند.
